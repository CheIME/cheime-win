# CheIME 输入与学习

CheIME 支持连续全拼、简拼和未完成拼音。输入 `nih` 时，候选中可以直接出现
“你好”；输入 `nh` 等简拼时也会按音节图检索，而不是把输入强制切成单一路径。

词库没有完整词条时，解码器会用已有的字词现场组句。例如输入 `nihao` 后，可先用
空格、数字键或鼠标选择一个只覆盖 `ni` 的候选，预编辑区会保留已选汉字和剩余的
`hao`；继续选择后，整段文本一次性提交。剩余拼音为空时按退格，会重新打开上一段
已确认内容，便于改选。

现场组成的新词在提交成功后进入 10 秒待确认期。期间它不会写入用户词库；10 秒后
才会成为高优先级用户候选。如果提交后没有继续输入、移动光标或切换焦点，并在同一
编辑上下文的原提交位置立即按退格，CheIME 会删除光标前一个字符并取消这次学习。
移动过光标时，退格仍执行普通删除，但不会错误撤销该词的学习记录。

静态词典翻译器可用以下选项分别控制行为，二者默认开启：

```yaml
engine:
  translators:
    - type: dict
      dictionary: rime_ice_base
      enable_completion: true
      enable_sentence: true
```
